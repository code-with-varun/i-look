High-Performance Architecture

Engineered For Accuracy & Complete Privacy

Developed by Runit Infotech, i-Look bridges native Windows Win32 API monitoring with modern reactive visualization to deliver accurate time sheets without cloud telemetry.

⏱️

Mandatory Start & End Times

Unlike standard screen time tools that only sum durations, i-Look captures the microsecond you open each application, the moment you switch away, and automatically calculates total session time.

🔕

System Tray Silent Mode

Closing the window minimizes i-Look to your Windows notification tray. It tracks seamlessly in the background with near-zero CPU and RAM overhead.

🚀

Run on Windows Startup

Starts automatically with Windows in background `--hidden` mode without popping up or stealing focus. Your timesheet begins tracking from the second you log in.

📅

Interactive Date Range Slicing

Select Today, Yesterday, Last 7 Days, Last 30 Days, or any custom date span. All charts, app rankings, and session tables update instantly.

📥

1-Click Excel / CSV Exports

Export your comprehensive audit trail with company metadata headers (Runit Infotech), ready for submission to employers, clients, or time sheet audits.

🔒

100% Offline & Private

Zero cloud servers. Zero telemetry. All sessions and configuration are stored locally under your Windows user profile (`%APPDATA%\i-look`).
